# Improvement areas

- No automated unit, API, or browser tests.
- The app has no user accounts or per-player data isolation.
- SQLite is stored on local disk and is unsuitable for ephemeral serverless storage.
- Mentor feedback is a small deterministic rule set and offers no engine evaluation.
- Dashboard review and progress data include illustrative sample values.
- API rate limiting, request quotas, and operational observability are not configured.
- The release workflow is present, but no version tag has been published yet.
